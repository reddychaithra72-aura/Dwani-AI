# Dwani AI

## 📌 Theme Alignment
**Wildcard Track**  
Dwani AI targets systemic digital exclusion across India's linguistic landscape. While global conversational AI engines prioritize text-heavy, high-resource languages, millions of citizens communicate via predominantly oral or unwritten languages (e.g., Lambadi, Tulu, Kodava, and various tribal dialects) that are entirely unsupported by platforms like Google Translate. 

Dwani AI introduces a universal speech-to-text pipeline that maps raw oral audio vectors directly into highly accessible regional and global scripts (English and Kannada text). By utilizing Lambadi (Gorboli) as our operational proof-of-concept, we demonstrate how speech technology can bridge critical real-time communication boundaries in healthcare, legal aid, and public administration.

## 🛠️ Mainframe Infrastructure & Tech Stack
- **Compute Platform:** Deployed directly on an **IBM LinuxONE (s390x Mainframe Architecture)** node instance.
- **Backend Architecture:** Native Python 3 backend micro-server engine providing sub-millisecond execution runtime with a zero compilation footprint, avoiding library friction on enterprise mainframe modules.
